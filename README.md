# TBATE - Site Informativo

## Escopo Fechado

### Objetivo do site
O objetivo deste projeto é desenvolver um site informativo e interativo sobre a obra The Beginning After The End (TBATE), apresentando informações sobre personagens, volumes, mundo e elementos da história de forma organizada e acessível.

### Público-alvo
O site é destinado para fãs da obra e pessoas interessadas em conhecer mais sobre o universo de TBATE.

### Paleta de cores e tipografia
Foi utilizada uma paleta baseada em tons escuros, com cores inspiradas no universo de fantasia da obra, transmitindo uma sensação de mistério e imersão.

A tipografia foi escolhida buscando manter boa leitura e uma aparência moderna.

### Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

Não foram utilizados frameworks.

---

# Estrutura do site

O site possui as seguintes páginas:

## Home
Página inicial com apresentação do tema e navegação para as demais áreas.

## Personagens
Apresenta informações sobre personagens importantes da obra.

## Volumes
Página com informações e capas dos volumes.

## Contato
Página com formulário interativo utilizando JavaScript para validação dos dados e mensagens de sucesso ou erro.

---

# Funcionalidades

- Navegação entre páginas
- Layout responsivo para diferentes tamanhos de tela
- Formulário com validação de email
- Mensagens de feedback para o usuário
- Interações utilizando JavaScript
- Botão de voltar ao topo
